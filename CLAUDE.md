# Nexora Digital — Claude Code Project Guide

## Project goal
Build and refine a polished, responsive website for a fictional web development agency brand named **Nexora Digital**.

## Current stack
- HTML5
- CSS3
- Vanilla JavaScript
- No build step or package installation is required for the starter version.

## Project files
- `index.html` — home page
- `services.html` — services
- `work.html` — concept portfolio
- `process.html` — project process
- `about.html` — about Nexora Digital
- `contact.html` — contact details
- `styles.css` — visual design, layout, responsive behavior
- `script.js` — mobile navigation, page interactions, and EUR/USD chart updates
- `cloudflare-worker.js` — secure proxy for the Twelve Data EUR/USD quote

## Design direction
- Premium, modern digital agency
- Dark navy background, electric blue and cyan accents
- Space Grotesk headings and DM Sans body text
- Spacious layouts, subtle borders, gradients, restrained glow effects
- Responsive on mobile, tablet, and desktop

## Important instructions
1. Read the existing files before making changes.
2. Keep the site responsive and accessible.
3. Do not remove existing sections unless asked.
4. Do not invent client names, testimonials, awards, statistics, or completed projects. Current portfolio entries are clearly marked as concept projects.
5. Keep the code clean and avoid unnecessary dependencies.
6. Test navigation, links, and mobile menu after changes.
7. The email address uses the reserved `.example` domain. Replace it with a real business email before launch.
8. The brand name is provisional. Check trademark and domain availability before commercial use.
9. Keep `TWELVE_DATA_API_KEY` in Cloudflare Worker secrets; never add provider credentials to frontend files or GitHub.

## How to work
Make one requested change at a time, explain which files changed, and provide clear local testing instructions.
